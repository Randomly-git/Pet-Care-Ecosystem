重要说明：由于CORS配置问题，当前无法直接通过前端访问社区API。以下是几种解决方案：
  1. 使用浏览器禁用安全策略（仅用于开发测试）
  2. 安装浏览器插件允许CORS
  3. 使用代理服务器

临时解决方案

chrome.exe --user-data-dir="C:/MyChromeDevUserData" --disable-web-security --disable-features=VizDisplayCompositor

安装以下插件之一：

  • Chrome: "CORS Unblock" 或 "Allow CORS"
  • Firefox: "CORS Everywhere"
