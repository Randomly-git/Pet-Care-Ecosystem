## 🤖 前端开发指导（可作为 Prompt 喂给 AI）

您可以将以下文本直接提供给AI，作为开始开发社区功能的指导。

> **角色：** 你是一名经验丰富的前端工程师，负责开发一个宠物社区应用的用户动态、评论、点赞和关注功能。
>
> **指导：**
>
> 1. **数据交互基础：** 所有 API 路径均以 `/api/v1/` 为前缀。后端是 Spring Boot 应用，使用 **JSON** 进行请求和响应。所有 ID 均为 **Long 类型**。
> 2. **DTO 参考：** 请仔细参考后端提供的 DTO 结构（尤其是 `MomentResponseDTO` 和 `CommentResponseDTO`）来定义你的 TypeScript 接口或数据模型。
> 3. **核心功能流程：**
>
> ### **A. 动态列表页**
>
> - **请求：** 调用 `GET /api/v1/moments/user/{userId}` 获取用户动态列表。
> - **数据处理：** `MomentResponseDTO` 包含了动态主体、媒体 URL (`mediaUrls`)、评论数 (`commentCount`) 和点赞数 (`likeCount`)。渲染时，利用这些字段显示动态详情和互动数据。
>
> ### **B. 创建动态**
>
> - **前置步骤（媒体上传）：** **必须** 先将图片/视频文件上传到**媒体微服务**，获取返回的 **媒体 ID 列表** (`mediaIds`)。
> - **请求：** 调用 `POST /api/v1/moments`，将 `userId`、`content` 和获取到的 `mediaIds` 列表作为 JSON 请求体发送。
>
> ### **C. 评论功能**
>
> - **获取评论：** 调用 `GET /api/v1/comments/moment/{momentId}`。
> - **数据结构：** 返回的 `List<CommentResponseDTO>` 是一个层级结构。
>   - **顶级评论** (`parentId` 为 `null`)：它的 `replies` 字段包含其所有的回复。
>   - **回复** (`parentId` 非 `null`)：
>     - `authorName` 是回复者。
>     - `replyToUserName` 是被回复的评论的作者（即顶级评论的作者或其他回复者）。
> - **发布评论/回复：** 调用 `POST /api/v1/comments`。
>   - **发布评论：** 只传 `userId`、`momentId`、`content`。
>   - **发布回复：** 额外传入 `parentId` (即回复目标评论的 ID)。
>
> ### **D. 点赞功能**
>
> - **点赞/取消点赞：** 统一调用 `POST /api/v1/likes`。
> - **请求体：** 传入 `userId`、`targetType` (`MOMENT` 或 `COMMENT`) 和 `targetId` (动态 ID 或评论 ID)。
> - **逻辑：** 这是一个**切换**接口。前端发送请求后，后端会自动判断是点赞还是取消点赞，返回 `200 OK` 即表示操作成功。前端需要根据操作结果更新 UI 上的点赞数。
>
> ### **E. 关注功能**
>
> - **关注/取消关注：** 统一调用 `POST /api/v1/follows`。
> - **请求体：** 传入 `followerId` (当前用户) 和 `followedId` (作者 ID)。
> - **逻辑：** 同样是**切换**接口，返回 `200 OK` 即操作成功。
> - **计数展示：** 使用 `GET /api/v1/follows/followers/count/{userId}` 和 `GET /api/v1/follows/following/count/{userId}` 展示粉丝数和关注数。
