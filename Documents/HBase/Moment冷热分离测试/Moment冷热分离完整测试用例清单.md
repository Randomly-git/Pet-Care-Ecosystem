# Moment 冷热分离完整测试用例清单 (重构版)

## 1. 测试用例设计说明
本设计采用**场景化测试建模**，将原子级的测试覆盖项 (TCI) 整合入业务路径中。测试用例划分为 5 个 Test Suite，分别对应系统的核心质量风险。

## 2. 测试用例表

| Test Suite (风险类别) | 用例 ID | 关联 TCI ID | 测试场景 | 测试数据/输入 | 测试步骤 | 预期结果 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **TS-1 Data Consistency (数据一致性)** | **TC-1-01** | TCI-STT-01, 05, TCI-DT-04 | **标准迁移全生命周期与自愈** | 状态: APPROVED, 访问时间: >168h | 1. 触发定时迁移任务至 COLD。<br>2. 手动回退 MySQL 记录至 MIGRATING 模拟崩溃。<br>3. 再次触发任务。 | 1. 正常经历 NONE->MIGRATING->COLD。<br>2. 自愈逻辑识别 HBase 已存在数据，跳过写入直接删除 MySQL。 |
| | **TC-1-02** | TCI-DT-03 | MySQL 删除超时 | 数据库死锁模拟 | 1. 触发迁移，在 HBase 写入成功后。 <br>2. 对该行动态加独占锁模拟超时。 | 状态保持 MIGRATING，事务安全回滚，MySQL 记录不丢失。 |
| **TS-2 Data Integrity (数据完整性)** | **TC-2-01** | TCI-STT-06, 07, 12 | **冷数据综合恢复链路** | 状态: COLD, 原审: REJECTED | 1. 列表页触发隐式恢复。<br>2. 页面按钮触发显式恢复。 | 1. 列表返回混合数据。<br>2. 恢复后 MySQL 状态为 NONE，且审核态保持为 REJECTED。 |
| | **TC-2-02** | TCI-DT-01, TCI-STT-03 | 存储基础设施故障回滚 | 网络超时/服务关闭 | 1. 触发迁移。<br>2. 在写入 HBase 瞬间关闭连接或注入超时。 | 全局事务回滚，MySQL 状态回滚为 NONE。 |
| | **TC-2-03** | TCI-DT-02 | 虚假写入成功校验 | Put=OK, Exists=False | 1. Mock HBase Put 返回成功。<br>2. Mock Exists 校验返回失败。 | 触发业务异常拦截，事务强制回滚，MySQL 数据不删除。 |
| **TS-3 Concurrency Control (并发控制)** | **TC-3-01** | TCI-STT-04, 11 | **迁移锁保护与物理删除** | 状态: MIGRATING | 1. 启动迁移任务，在 MIGRATING 期间模拟用户点赞/评论/修改。<br>2. 模拟迁移中管理员/用户执行物理删除。 | 1. 系统抛出 IllegalStateException 拒绝点赞等操作。<br>2. 物理删除成功清理热/冷库记录，不产生数据残留。 |
| **TS-4 System Stability (系统稳定性)** | **TC-4-01** | TCI-STT-02, 13, TCI-BVA-01-D | **迁移准入拦截与解锁** | 评论数: 2001, 状态: PENDING | 1. 分别使用该数据触发迁移。 | 系统识别不符准入条件，迁移不启动，状态保持原样，不进入 MIGRATING。 |
| | **TC-4-02** | TCI-STT-Neg-01 | **重复审核拦截** | 状态: APPROVED/REJECTED | 管理员对已审核动态再次点击“通过”。 | 接口拒绝请求或返回 0 更新，不修改已有状态。 |
| | **TC-4-03** | TCI-STT-Neg-02 | **重复恢复拦截** | 状态: NONE (ACTIVE) | 模拟接收到 MQ 的 RESTORE 事件。 | 识别到热记录已存在，幂等跳过处理，不发生主键冲突。 |
| **TS-5 Functionality & Availability (功能可用性)** | **TC-5-01** | TCI-STT-09, 14 | 审核可见性与流转 | 状态: PENDING | 1. 匿名用户尝试查询。<br>2. 管理员执行审核操作。 | 1. PENDING 状态全站不可见。<br>2. 状态根据操作正确流向 APP/REJ。 |
| | **TC-5-02** | TCI-STT-10, 08 | 内容维护与热度重置 | 动作: Update / View | 1. 修改已通过动态内容。<br>2. 用户访问动态详情页。 | 1. 审核态重置为 PENDING。<br>2. last_access 时间更新，重置冷却计数。 |
| | **TC-5-03** | TCI-BVA-01-A, B, C | 评论数容量边界 | 评论数: {0, 1999, 2000} | 分别使用不同评论数的动态触发迁移。 | 预期结果：均成功归档并删除 MySQL 记录。 |
| | **TC-5-04A** | TCI-BVA-02-B, C | REJ 时间有效边界 | 时间: {72h, 73h} | 针对被拒绝动态触发迁移任务。 | 预期结果：达到 3 天阈值，开始执行迁移过程。 |
| | **TC-5-04B** | TCI-BVA-02-A | REJ 时间无效边界 | 时间: {71h} | 针对被拒绝动态触发迁移任务。 | 预期结果：未达阈值，任务静默跳过该记录。 |
| | **TC-5-05A** | TCI-BVA-03-B | APP 时间有效边界 | 时间: {168h, 169h} | 针对已通过动态触发迁移任务。 | 预期结果：达到 7 天阈值，开始执行迁移过程。 |
| | **TC-5-05B** | TCI-BVA-03-A | APP 时间无效边界 | 时间: {167h} | 针对已通过动态触发迁移任务。 | 预期结果：未达阈值，任务静默跳过该记录。 |
