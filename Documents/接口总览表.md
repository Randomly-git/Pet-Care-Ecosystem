| 微服务       | 接口路径 (API Endpoint)                     | 接口功能 (Function）                      |
| ------------ | ------------------------------------------- | ----------------------------------------- |
| **日常记录** | `POST /api/auth/login`                      | 用户登录并获取 JWT Token                  |
|              | `POST /api/auth/register`                   | 新用户账号注册                            |
|              | `GET /api/users/me`                         | 获取当前登录用户的详细个人资料            |
|              | `POST /api/pets`                            | 创建新的宠物档案 (含性别、生日、品种)     |
|              | `GET /api/pets/{petId}`                     | 查询特定宠物的基本信息及活跃记录数        |
|              | `GET /api/pets/user/{userId}`               | 获取指定用户名下的所有宠物列表            |
|              | `POST /api/activities/records/pet/{petId}`  | 为宠物添加活动记录 (支持上传图片/视频)    |
|              | `GET /api/activities/records/pet/{petId}`   | 搜索/筛选宠物历史活动记录 (支持日期范围)  |
|              | `PUT /api/activities/records/{recordId}`    | 更新活动记录的内容或关联的媒体文件        |
|              | `DELETE /api/activities/records/{recordId}` | 删除活动记录，并同步清理磁盘/云端资源     |
|              | `GET /api/status/pet/{petId}`               | 获取宠物的状态分类 (如: 健康、疫苗、驱虫) |
|              | `GET /api/status/timeline/{petId}`          | 冷数据从 HBase 查询历史状态变更轴         |
|              | `POST /api/status/records`                  | 新增宠物状态变更记录                      |
|              | `PUT /api/status/records/{id}/stop`         | 停止某个持续性状态记录 (设置结束日期)     |
| **活动提醒** | `GET /api/reminders/pet/{petId}/overdue`    | 获取宠物已过期的待办提醒列表              |
|              | `PUT /api/reminders/{id}/confirm`           | 确认完成提醒 (自动转为活动记录)           |
|              | `PUT /api/reminders/{id}/postpone`          | 将提醒任务推迟一天                        |
|              | `POST /api/reserved-activities`             | 为宠物预定单次未来活动                    |
|              | `GET /api/fixed-activities/pet/{petId}`     | 查看宠物所有周期性活动配置                |
|              | `POST /api/reserved-activities`             | 创建单次未来活动预定                      |
|              | `PUT /api/reserved-activities/date`         | 修改单次预定的日期                        |
| **宠物空间** | `POST /api/v1/moments`                      | 发布社区动态 (支持关联多个媒体 ID)        |
|              | `GET /api/v1/moments/all`                   | 分页获取全平台动态 (含作者信息与点赞数)   |
|              | `POST /api/v1/likes`                        | 切换对动态或评论的点赞状态                |
|              | `POST /api/v1/comments`                     | 发表评论或回复特定评论                    |
|              | `POST /api/v1/follows`                      | 关注或取消关注其他宠物主                  |
|              | `GET /api/v1/admin/moments/pending`         | 管理端获取待审核的社区动态列表            |
|              | `PUT /api/v1/admin/moments/{id}/audit`      | 对动态进行审核 (通过/拒绝并记录原因)      |
|              | `GET /api/v1/notifications`                 | 分页获取点赞、评论、关注等系统通知        |
|              | `PUT /api/v1/notifications/{id}/read`       | 标记单条通知为已读状态                    |
|              | `GET /ws`                                   | WebSocket 实时推送新消息提醒              |
| **媒体文件** | `POST /api/media/upload`                    | 上传原始媒体文件 (生成本地路径及元数据)   |
|              | `GET /api/media/related/{type}/{id}`        | 获取某项业务 (如动态) 下的所有媒体列表    |
|              | `POST /api/media/{id}/restore`              | 冷数据触发归档文件从冷存储恢复到热区      |
|              | `PATCH /api/media/batch/related`            | 批量将孤儿媒体文件绑定到具体业务 ID       |
| **智能分析** | `GET /api/llm/pet-status/{petId}`           | 调用 LLM 对宠物近期健康数据进行总结       |
|              | `GET /api/stats/activity/{petId}`           | 获取宠物活动频率与种类的可视化统计数据    |
