## 🌟 核心页面说明

### 1. ActivitiesView.vue - 活动记录页面
**路径**: `/activities`

**功能**:
- 查看宠物活动记录（喂食、遛狗、玩耍等）
- 添加新活动记录（支持媒体上传）
- 编辑/删除活动记录
- **AI 状态总结**: 每个宠物卡片有 "✨ AI总结" 按钮，调用 LLM 服务生成宠物状态分析报告

**关键 API**:
- `getActivityRecords(petId)` - 获取活动记录
- `createActivityRecord()` - 创建活动记录
- `getPetStatusSummary(petId)` - **AI 状态总结** ⭐

**媒体处理**: 前端单独调用 `getRelatedMedia('activity', recordId)` 获取媒体文件

---

### 2. MomentsView.vue - 社区动态页面
**路径**: `/moments`

**功能**:
- 查看用户发布的社区动态
- 发布新动态（支持多图上传）
- 点赞、评论功能

**关键 API**:
- `getUserMoments(userId)` - 获取用户动态
- `createMoment({ userId, content, mediaIds })` - 创建动态
- `getRelatedMedia('MOMENT', momentId)` - 获取媒体文件

**媒体处理**: ⭐ **已修复** - 前端单独调用 `getRelatedMedia` API 获取媒体，不依赖后端返回的 `mediaUrls`

---

### 3. PetSpace.vue - 宠物空间页面
**路径**: `/space`

**功能**:
- 宠物活动时间线展示
- 发布动态
- 查看宠物活动统计

## 📡 API 层结构

### 基础配置: `api/index.js`
```javascript
// 基础 URL 配置
baseURL: '/api'

// 通过 Vite 代理转发到网关
// 开发环境: http://localhost:9000
```

### 各微服务 API 路径

| 微服务 | API 路径 | 文件 |
|--------|----------|------|
| 活动记录 | `/api/activity/*` | `activities.js` |
| 宠物管理 | `/api/pets/*` | `pets.js` |
| 社区动态 | `/api/v1/*` | `community.js` ⭐ |
| 媒体文件 | `/api/media/*` | `media.js` |
| AI 服务 | `/api/llm/*` | `llm.js` ⭐ |
| 统计数据 | `/api/stats/*` | `statistics.js` |
| 用户认证 | `/api/auth/*` | `auth.js` |

### ⚠️ 重要说明

**社区动态 API 路径特殊**:
- `COMMUNITY_BASE_URL = '/v1'`
- 最终路径: `/api/v1/moments` (因为 `index.js` 已有 `/api` 前缀)
- **不要写成 `/api/v1`**，否则会导致路径重复: `/api/api/v1/moments`

## 🔧 Vite 配置 (vite.config.js)

### 代理配置 ⭐
```javascript
proxy: {
  '/api': {
    target: 'http://localhost:9000',  // 统一网关入口
    changeOrigin: true,
    secure: false,
  },
  '/uploads': {
    target: 'http://localhost:9000',
    changeOrigin: true,
    secure: false
  }
}
```

**关键点**:
- 所有 API 请求通过网关 `localhost:9000` 路由
- 不再直接访问各微服务端口 (8081, 8082, 8084, etc.)

## 🐛 已知问题与修复

### 1. 社区动态媒体文件不显示
**问题**: 后端返回的 `mediaUrls` 为空数组
**解决方案**: 前端单独调用 `getRelatedMedia('MOMENT', momentId)` 获取媒体
**位置**: `MomentsView.vue` 的 `loadMoments()` 函数

### 2. AI 总结页面崩溃
**问题**: 正则表达式 `/**/g` 语法错误导致 `g is not defined`
**解决方案**: 改为 `/\*\*/g` 正确转义星号
**位置**: `ActivitiesView.vue:2410`

### 3. 社区 API 404 错误
**问题**: `COMMUNITY_BASE_URL` 配置错误导致路径重复
**解决方案**: 使用 `/v1` 而不是 `/api/v1`
**位置**: `api/community.js:9`

## 📝 给团队成员的建议

### 新增功能时:
1. **API 层**: 在 `src/api/` 下创建对应微服务的 API 文件
2. **视图**: 在 `src/views/` 下创建页面组件
3. **路由**: 在 `router/index.js` 中注册路由
4. **状态管理**: 如需全局状态，在 `stores/` 下创建 store

### 调用 API 时:
- 优先使用 `src/api/` 下已封装好的函数
- 媒体文件统一使用 `getRelatedMedia(relatedType, relatedId)` 获取
- 不要直接调用 `src/services/` 下的旧版 API

### 样式开发:
- 优先使用 Element Plus 组件
- 使用 `design-tokens.css` 中的设计变量
- 保持组件样式在 `<style scoped>` 块中
