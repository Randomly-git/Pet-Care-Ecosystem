# 📺 媒体微服务 API 调用说明

本微服务负责处理所有文件的上传、存储和关联关系管理。

**根路径：** `/api/media`

## 1. 基础数据格式

所有 API 响应均采用统一的 `ApiResponse<T>` 封装。

### 1.1. 统一响应格式 (`ApiResponse<T>`)

| **字段名** | **类型** | **描述**                                   | **示例值**               |
| ---------- | -------- | ------------------------------------------ | ------------------------ |
| `code`     | `int`    | 业务状态码。`20000` 表示成功。             | `20000`                  |
| `message`  | `String` | 响应消息。                                 | `"操作成功"`             |
| `data`     | `T`      | 实际返回的业务数据（类型取决于具体 API）。 | `{ MediaResponse 列表 }` |

### 1.2. 媒体文件响应 DTO (`MediaResponse`)

这是媒体文件信息的标准结构，通常作为 `ApiResponse` 中的 `data` 字段返回。

| **字段名**    | **类型**        | **描述**                                                     |
| ------------- | --------------- | ------------------------------------------------------------ |
| `mediaId`     | `Long`          | 媒体文件的唯一 ID。                                          |
| `fileUrl`     | `String`        | 文件的访问 URL（**现为 COS 静态网站域名，前端直接用于展示**）。 |
| `relatedType` | `String`        | 关联业务类型（**MOMENT, USER_AVATAR, ACTIVITY, STATUS**）。  |
| `relatedId`   | `Long`          | 关联的业务 ID（如：动态 ID，用户 ID）。                      |
| `fileName`    | `String`        | 文件原始名称。                                               |
| `fileType`    | `String`        | 文件类型（如：`image/jpeg/pdf/mp4`）。                       |
| `uploadTime`  | `LocalDateTime` | 文件上传时间。                                               |

------

## 2. 媒体 API 接口详情

### 2.1. 文件上传 (前端直接调用)

此接口通常由前端直接调用，将文件上传到存储服务并获取一个临时 ID。

| **属性**         | **值**                                    |
| ---------------- | ----------------------------------------- |
| **用途**         | 上传文件到服务器，获取文件信息和临时 ID。 |
| **URI**          | `/api/media/upload`                       |
| **Method**       | `POST`                                    |
| **Content-Type** | `multipart/form-data`                     |

#### 🔹 请求参数

此接口要求通过 `multipart/form-data` 方式上传，所有参数都以 `key: value` 形式传输。

| **参数名**    | **类型** | **描述**                                                     | **是否必须** |
| ------------- | -------- | ------------------------------------------------------------ | ------------ |
| `file`        | `File`   | 要上传的媒体文件。                                           | 必填         |
| `userId`      | `Long`   | 上传文件的用户 ID。                                          | 必填         |
| `relatedType` | `String` | 关联的业务类型（**临时关联**，例如：`TEMP` 或业务类型如 `MOMENT`）。 | 必填         |
| `relatedId`   | `Long`   | 关联的业务 ID（**临时关联**，如果业务实体尚未创建，可传 `0` 或其他临时 ID，取决于后端逻辑）。 | 必填         |

#### 🔹 响应格式

| **状态码** | **响应体 (Body)**            | **描述**                                                     |
| ---------- | ---------------------------- | ------------------------------------------------------------ |
| `200 OK`   | `ApiResponse<MediaResponse>` | 上传成功，`data` 字段返回该文件的 `MediaResponse` 对象，包含其 `mediaId`。 |

------



### 2.2. 批量关联媒体文件

此接口用于将一批已上传（但尚未关联）的临时文件与特定的业务实体（如新创建的动态）进行绑定。

| **属性**   | **值**                                     |
| ---------- | ------------------------------------------ |
| **用途**   | 关联媒体文件到业务实体（如 `PetMoment`）。 |
| **URI**    | `/api/media/related/batch`                 |
| **Method** | **`PATCH`**                                |

#### 🔹 请求体 (`MediaBatchUpdateRequest`)

| **字段名**     | **类型**     | **约束**    | **描述**                                    |
| -------------- | ------------ | ----------- | ------------------------------------------- |
| `mediaIds`     | `List<Long>` | `@NotEmpty` | 需要关联的媒体文件 ID 列表。                |
| `relatedType`  | `String`     | `@NotBlank` | 关联的业务类型，例如 **`MOMENT`**。         |
| `newRelatedId` | `Long`       | `@NotNull`  | **新的** 关联 ID（例如：新创建的动态 ID）。 |

#### 🔹 响应格式

| **状态码**                  | **响应体 (Body)**   | **描述**                                 |
| --------------------------- | ------------------- | ---------------------------------------- |
| `200 OK`                    | `ApiResponse<Void>` | 关联成功，`data` 为 `null`。             |
| `400 Bad Request`           | `ApiResponse<Void>` | 请求体校验失败（例如 `mediaIds` 为空）。 |
| `500 Internal Server Error` | `ApiResponse<Void>` | 内部系统错误。                           |

------

### 2.3. 获取关联的媒体文件列表

此接口用于获取特定业务实体（如某条动态）下的所有媒体文件 URL，是社区服务进行数据聚合的关键。

| **属性**   | **值**                                         |
| ---------- | ---------------------------------------------- |
| **用途**   | 根据业务 ID 获取所有媒体文件的信息。           |
| **URI**    | `/api/media/related/{relatedType}/{relatedId}` |
| **Method** | `GET`                                          |

#### 🔹 URL 参数

| **参数名**      | **描述**                     | **示例**                          |
| --------------- | ---------------------------- | --------------------------------- |
| `{relatedType}` | 业务类型，例如：**`MOMENT`** | `/api/media/related/MOMENT/`      |
| `{relatedId}`   | 业务 ID，例如：动态 ID       | `/api/media/related/MOMENT/12345` |

#### 🔹 响应格式

| **状态码**      | **响应体 (Body)**                  | **描述**                                   |
| --------------- | ---------------------------------- | ------------------------------------------ |
| `200 OK`        | `ApiResponse<List<MediaResponse>>` | 成功返回该业务实体关联的所有媒体文件列表。 |
| `404 Not Found` | `ApiResponse<Void>`                | 未找到任何关联的媒体文件。                 |

------

### 2.4. 删除关联的媒体文件

此接口用于删除与特定业务实体关联的所有媒体文件，通常在删除动态时调用，以清理存储资源。

| **属性**   | **值**                                             |
| ---------- | -------------------------------------------------- |
| **用途**   | 删除与业务实体关联的所有媒体文件（包括物理删除）。 |
| **URI**    | `/api/media/related/{relatedType}/{relatedId}`     |
| **Method** | `DELETE`                                           |

#### 🔹 URL 参数

| **参数名**      | **描述**                     | **示例**                          |
| --------------- | ---------------------------- | --------------------------------- |
| `{relatedType}` | 业务类型，例如：**`MOMENT`** | `/api/media/related/MOMENT/`      |
| `{relatedId}`   | 业务 ID，例如：动态 ID       | `/api/media/related/MOMENT/12345` |

#### 🔹 响应格式

| **状态码**                  | **响应体 (Body)**   | **描述**               |
| --------------------------- | ------------------- | ---------------------- |
| `200 OK`                    | `ApiResponse<Void>` | 成功删除所有关联文件。 |
| `500 Internal Server Error` | `ApiResponse<Void>` | 删除操作失败。         |

### 



### 1. 核心 DTO 变动

- **`MediaBatchUpdateRequest`**: 用于在创建动态后，将临时上传的图片正式关联到动态 ID。
- **`MediaResponse`**: 包含 `fileUrl`（COS 访问地址）和 `relatedId`（关联的业务 ID）。

### 2. 接口列表

| **方法**   | **路径**               | **说明**                                 | **关键参数**                              |
| ---------- | ---------------------- | ---------------------------------------- | ----------------------------------------- |
| **POST**   | `/upload`              | **文件预上传**。获取 `mediaId`。         | `file`, `userId`, `relatedType='TEMP'`    |
| **PATCH**  | `/batch/related`       | **批量关联**。将图片绑定到动态。         | `mediaIds`, `newRelatedId`, `relatedType` |
| **GET**    | `/batch`               | **[新增] 批量获取**。支持一次查多个 ID。 | `relatedType`, `relatedIds` (逗号分隔)    |
| **GET**    | `/related/{type}/{id}` | 获取单个业务实体的媒体。                 | `relatedType`, `relatedId`                |
| **DELETE** | `/related/{type}/{id}` | 删除关联的所有文件及云端存储。           | `relatedType`, `relatedId`                |
