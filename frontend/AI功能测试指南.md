## 🚀 如何测试

### 测试前准备：

1. **确认服务运行**
   ```bash
   # 确认网关在运行
   curl http://localhost:9000/actuator/health

   # 确认LLM服务在Nacos中注册
   # 访问 http://192.168.147.1:8080/nacos
   ```

2. **启动前端**
   ```bash
   cd frontend
   npm run dev
   ```

### 测试步骤：

#### 第1步：访问活动页面
打开浏览器访问：`http://localhost:5173/activities`

#### 第2步：找到宠物卡片
在"我的宠物"区域，你应该看到每个宠物卡片下方都有一个蓝色的"✨ AI总结"按钮

#### 第3步：点击AI总结按钮
- 点击任意宠物的"✨ AI总结"按钮
- 应该立即弹出对话框
- 显示"AI正在分析中..."加载动画

#### 第4步：查看AI分析结果
- 等待几秒后，AI分析完成
- 对话框中显示详细的宠物状态分析报告
- 报告包含：
  - 宠物健康状况评估
  - 活动水平分析
  - 智能建议

#### 第5步：复制报告（可选）
- 点击"复制报告"按钮
- 报告内容已复制到剪贴板
- 可以粘贴到其他地方

## 🐛 故障排查

### 问题1：点击按钮无反应
**检查**：
1. 打开浏览器F12控制台
2. 查看是否有JavaScript错误
3. 检查网络请求是否发送

**解决**：
- 确认LLM服务API文件存在：`frontend/src/api/llm.js`
- 确认网关正在运行

### 问题2：AI分析失败
**可能原因**：
1. LLM服务未启动
2. LLM服务未在Nacos注册
3. 网关路由配置错误
4. 宠物没有足够的活动数据

**解决**：
1. 检查网关：`curl http://localhost:9000/actuator/health`
2. 检查Nacos服务列表
3. 确认宠物有活动记录
4. 查看浏览器控制台错误信息

### 问题3：显示"分析失败，请检查网络连接"
**检查**：
1. 网关是否在9000端口运行
2. LLM后端服务是否在8086端口运行
3. 浏览器控制台的网络请求是否返回错误

**解决**：
```bash
# 测试网关连接
curl http://localhost:9000/api/llm/pet-status/summary/12

# 查看网关日志
# 查看LLM服务日志
```

### 问题4：显示"AI分析数据不足"
**原因**：该宠物没有足够的活动记录供AI分析

**解决**：
- 为该宠物添加一些活动记录
- 重新点击AI总结按钮
