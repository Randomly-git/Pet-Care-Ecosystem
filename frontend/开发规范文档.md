## 🚀 API调用规范

### ❌ 错误做法
```javascript
// 1. 直接写死端口
const BASE_URL = 'http://localhost:3000/api/media'  // ❌
const BASE_URL = 'http://localhost:8081'            // ❌

// 2. 混用不同端口
fetch('http://localhost:3001/api/community/moments') // ❌
fetch('http://localhost:8083/api/v1/moments')        // ❌
```

### ✅ 正确做法
```javascript
// 1. 使用相对路径，通过前端代理
const BASE_URL = '/api/media'          // ✅
const BASE_URL = '/api/community'      // ✅

// 2. 统一使用前端代理配置
fetch('/api/media/upload')             // ✅
fetch('/api/community/moments')        // ✅
```

## 🏗️ 微服务架构说明

### 当前服务端口分配
| 服务名称 | 端口 | 前端代理路径 | 说明 |
|---------|------|-------------|------|
| Frontend (Vue) | 5173 | - | 前端开发服务器 |
| Petcare Backend | 8082 | `/api/*` | 主要业务逻辑 |
| Media Backend | 8081 | `/api/media/*` | 媒体文件处理 |
| Community Backend | 8083 | `/api/community/*` | 社区功能 |

### 前端代理配置 (vite.config.js)
```javascript
proxy: {
  // 默认代理到 petcare-backend
  '/api': {
    target: 'http://localhost:8082',
    changeOrigin: true
  },

  // 社区服务代理
  '/api/community': {
    target: 'http://localhost:8083',
    changeOrigin: true,
    rewrite: (path) => path.replace('/api/community', '/api/v1')
  },

  // 媒体服务代理
  '/api/media': {
    target: 'http://localhost:8081',
    changeOrigin: true,
    rewrite: (path) => path.replace(/^\/api\/media/, '/api/v1/media')
  }
}
```

## ⚙️ 环境配置规范

### 1. 使用统一API配置文件
```javascript
// 推荐：使用 api-unified.js
import { mediaAPI, communityAPI } from '@/services/api-unified'

// 媒体上传
await mediaAPI.uploadFile(file, userId, 'MOMENT')

// 社区动态
await communityAPI.createMoment(data)
```

### 2. 环境变量配置
```bash
# .env.development
VITE_API_GATEWAY=http://localhost:8082
VITE_MEDIA_SERVICE=http://localhost:8081
VITE_COMMUNITY_SERVICE=http://localhost:8083
```

### 3. API端点规范
- 所有API调用都使用相对路径
- 路径必须以 `/` 开头
- 统一通过前端代理转发

```javascript
// ✅ 正确示例
const response = await fetch('/api/users/me')
const fileUpload = await upload(file, '/api/media/upload')

// ❌ 错误示例
const response = await fetch('http://localhost:8082/api/users/me')
const fileUpload = await upload(file, 'http://localhost:8081/api/media/upload')
```

## 🛠️ 常见问题解决

### 问题1: 404 Not Found
**现象**: API请求返回404错误
**原因**: 端口配置错误或路径不匹配
**解决**:
1. 检查是否使用了错误的端口
2. 确认API路径是否正确
3. 验证后端服务是否运行

```javascript
// 检查服务状态
curl http://localhost:8082/api/users/me
curl http://localhost:8083/api/v1/moments
curl http://localhost:8081/api/v1/media
```

### 问题2: CORS跨域错误
**现象**: 控制台显示CORS策略错误
**原因**: 前端直接调用后端API，未通过代理
**解决**: 使用相对路径，通过前端代理

```javascript
// ❌ 错误 - 直接调用后端
fetch('http://localhost:8083/api/v1/moments')

// ✅ 正确 - 通过代理
fetch('/api/community/moments')
```

### 问题3: 端口冲突
**现象**: 多个服务使用同一端口
**原因**: 开发环境配置混乱
**解决**: 按规范分配端口，清理冲突进程

```bash
# 查看端口占用
netstat -ano | findstr :8081
netstat -ano | findstr :8082
netstat -ano | findstr :8083

# 终止进程
taskkill /PID <进程ID> /F
```

## 🔄 迁移指南

### 从旧配置迁移到新规范

1. **替换硬编码URL**
```javascript
// 旧代码
fetch('http://localhost:3000/api/media/upload')

// 新代码
fetch('/api/media/upload')
```

2. **使用统一API服务**
```javascript
// 旧代码
import { uploadMedia } from './api/media'

// 新代码
import { mediaAPI } from '@/services/api-unified'
await mediaAPI.uploadFile(file, userId)
```

3. **更新环境配置**
```javascript
// 删除这些配置
const BASE_URL = 'http://localhost:3000'
const MEDIA_URL = 'http://localhost:8081'

// 使用环境变量
const BASE_URL = import.meta.env.VITE_API_GATEWAY
```
